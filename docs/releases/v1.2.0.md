## Perlustra 1.2.0

本版本为 Perlustra 增加了完整的离线解压、压缩与压缩包内直接预览能力，全程复用 macOS 系统自带库，不增加额外依赖。

### 新增与改进

- **压缩包安全解压**：打开压缩包后，可一键「解压到当前」「解压到…」或仅「解压选中」条目；自动拦截路径穿越和软/硬链接逃逸，零散多文件自动新建同名文件夹避免打散原目录，重名文件自动顺延编号不静默覆盖；后台流式解压支持实时进度与随时取消。
- **包内单文件直接预览**：在压缩包视图里双击任意未加密文件即可在新标签页临时打开预览（PDF、表格、图片、Markdown、代码等均走原生渲染器），不会写入最近打开，关闭标签页或退出应用后自动清理临时文件。
- **侧栏右键压缩与快捷解压**：在侧栏右键文件或文件夹，可一键压缩为 **ZIP** 或 **tar.gz**（自动过滤 `.DS_Store` 和 `._*` 隐藏垃圾文件，原子写入不留损坏残包）；右键压缩包可直接解压到当前文件夹。

完整更新记录见 [CHANGELOG.md](https://github.com/xiaolv-home/perlustra/blob/v1.2.0/CHANGELOG.md)。
