## Perlustra 1.2.1

这是一次安全性、稳定性与体验细节的集中加固更新，同时补上了侧栏多选批量压缩功能。

### 新增与改进

- **侧栏多选操作**：按住 `⌘` 或 `⇧` 可在侧栏多选文件与文件夹，右键一键打包成同一个 **ZIP** / **tar.gz**，或批量移入废纸篓；普通单击仍保持直接打开。
- **表格与编辑器修复**：修复编辑 `.xlsx` 在表尾连续新增多行时行号顺序导致 Excel 报错的问题；修正 Markdown 编码降级提示中的原编码名称显示；优化 AI 生成表格的目录定位与多窗口会话隔离。
- **安全与稳定性加固**：本地网页 `localStorage` 按文件夹隔离，跨目录本地文件链接需经用户确认才打开；加固 API Key `0600` 原子写入与 `libmpv` 动态库路径校验；修复视频播放器关闭竞态、子进程管道死锁、AI 命令取消响应及特殊 GitHub 技能链接解析崩溃。

完整更新记录见 [CHANGELOG.md](https://github.com/xiaolv-home/perlustra/blob/v1.2.1/CHANGELOG.md)。
